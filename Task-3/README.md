# Task 3 – Deep-Dive Analysis & Interactive Dashboard

This project was completed as part of the **ApexPlanet Data Analytics Internship**.

## Project Overview

Task 3 focused on performing deep-dive analysis of sales and customer data, defining important business KPIs, performing customer segmentation, and developing an interactive dashboard for business decision-making.

## Key Skills

- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit
- KPI Analysis
- Customer Segmentation
- Data Visualization
- Business Insights
- Git & GitHub

## Key Work

- Defined important business KPIs
- Analyzed sales and customer data
- Performed customer segmentation
- Analyzed purchasing behavior
- Studied sales by category and city
- Analyzed monthly sales trends
- Created an interactive Streamlit dashboard
- Added filters for gender, category, city, and date
- Provided business insights and recommendations
- Deployed the dashboard using Streamlit Community Cloud

## Key KPIs

- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Total Quantity

## Key Deliverables

- KPI analysis
- Customer segmentation analysis
- Interactive Streamlit dashboard
- Business insights report
- Analysis charts
- Deployed live dashboard
