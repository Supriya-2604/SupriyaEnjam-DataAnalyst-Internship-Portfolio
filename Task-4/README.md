# Task 4 – Data Storytelling & Statistical Validation

This project was completed as part of the **ApexPlanet Data Analytics Internship**.

## Project Overview

Task 4 focused on transforming the analysis from previous tasks into a clear business story, validating a business hypothesis using statistical testing, and presenting the findings through a professional PowerPoint presentation.

- Interpreted p-values and statistical results
- Developed actionable business recommendations

## Hypothesis Testing

### Business Question

**Is there a statistically significant difference in average sales between male and female customers?**

An independent two-sample t-test was performed using a significance level of **α = 0.05**.

The statistical results include:

- Male average sales
- Female average sales
- T-statistic
- P-value

The results are documented in the project's hypothesis testing output.
