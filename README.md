# Statistical Analysis

As part of Task 4, a business hypothesis was tested:

**Is there a statistically significant difference in average sales between male and female customers?**

An independent two-sample t-test was used with a significance level of **0.05**.

The analysis included:

- Hypothesis formulation
- Statistical testing
- T-statistic
- P-value
- Business interpretation
- Recommendations
